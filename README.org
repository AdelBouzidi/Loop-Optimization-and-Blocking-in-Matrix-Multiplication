# Loop Optimization and Blocking in Matrix Multiplication Algorithms

Projet académique réalisé dans le cadre d’un travail pratique portant sur l’optimisation des boucles dans un algorithme de multiplication de matrices.

Le projet se concentre sur l’analyse des dépendances de données, les permutations de boucles et les techniques de blocking (tiling) afin d’améliorer les performances d’exécution et l’utilisation du cache processeur.

---

# Objectifs du projet

Ce travail a pour objectif :

- d’analyser les dépendances de données dans des boucles imbriquées
- d’étudier l’impact des permutations de boucles sur les performances
- d’optimiser un algorithme de multiplication de matrices (`ssgemm`)
- d’évaluer différentes stratégies de blocking (tiling)
- de comparer plusieurs tailles de blocs
- d’analyser les performances à travers les cycles processeur
- d’améliorer la localité mémoire et l’efficacité du cache

---

# Technologies et outils utilisés

- Langage C/C++
- CMake
- Linux
- Gnuplot
- Algorithmes BLAS (`ssgemm`)
- Optimisations de boucles
- Blocking / Tiling
- Analyse de performances CPU
